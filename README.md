# 贴境 NoteScape

Windows 桌面端便签画布应用。

## 开发命令

```bash
pnpm install
pnpm tauri dev
pnpm tauri build
```

## 常用快捷键

- `Ctrl+F`：聚焦搜索
- `Ctrl+N`：新建便签
- `Ctrl+S`：手动保存
- `Ctrl+C` / `Ctrl+V`：复制/粘贴便签
- `Ctrl+D`：复制选中便签
- `Ctrl+Z` / `Ctrl+Y`：撤销/重做
- `Ctrl+Plus` / `Ctrl+Minus` / `Ctrl+0`：缩放
- `Delete`：删除选中便签
- `Space + Drag` / 中键拖拽：平移画布
